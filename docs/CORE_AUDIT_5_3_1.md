# Аудит META Core и кодинг-агента — кандидат 5.3.1

5 ноября 2026 года. Проверены исходники Core, обе реализации агента, маршрутизация
интерфейса, обработка изображений, сборка и установщик. Синтаксическая проверка
охватывает 86 Python-файлов. Это не доказательство отсутствия всех ошибок и не
полный построчный аудит исполняемого слоя `desktop_base.bin`.
Рабочая установка пока не заменяется; публикация требует отдельного подтверждения.

| Средний | Упаковщик пропускал некоторые приватные расширения | Запрещены .pre11, базы, локальные конфиги, ключи и state-каталоги; публичный certifi CA bundle разрешён отдельно |

Условие «официальный домен» консервативное: отсутствие в списке не означает,
что сайт плохой; оно означает, что META не может подтвердить его официальный статус.
Пользователь может дать точную ссылку или добавить домен командой `/domains allow`.
Это правило уменьшает полноту поиска и не доказывает владельца каждого сайта.

## Что осталось слабым

1. **Качество и скорость модели.** Новый алгоритм не превращает 4B/9B в более сильную
   модель. Реальный небольшой проект на 4B занял 156,47 с. Сравнения качества 9B
   в этом прогоне нет; обычный чат и большой код — разные нагрузки.
2. **Два агента.** Desktop Sessions и основной meta5.execute пока не объединены.
   Общие правила задачи добавлены в оба, но инструменты и сохранение различаются.
3. **Проверки приложения.** Агент выполняет статические проверки. Автоматического
   обязательного запуска браузера, проверки адаптивности, доступности и всех сценариев
   внутри каждого пользовательского задания ещё нет. Браузерная проверка в этом
   аудите — отдельная проверка разработчика.
4. **Внешний вид по референсу.** Текст страницы не равен скриншоту. Фото теперь можно
   приложить, но vision-наблюдения могут быть неточны; визуальная идентичность не обещается.
5. **JavaScript/TypeScript/CSS.** Node нужен для синтаксической проверки JS. На другом
   компьютере без Node она будет not_run. CSS/TS/JSX, сборки и зависимости не получили
   универсального компилятора; автозапуска чужих скриптов без согласия нет.
6. **Интернет.** Чёрный список и репутация неполны. Текущая проверка официального
   источника может отвергнуть настоящий неизвестный домен. SPA, навигация, реквизиты
   и ограничения сети мешают извлечению. Два живых запроса — маленькая выборка.
7. **Проверка фактов.** Реальная цитата проверяется кодом, её логический смысл —
   локальной моделью. Ошибочное подтверждение всё ещё возможно.
8. **Память.** 17/20 перефразирований на калибровочной выборке фазы 11, а не независимой.
   Морфология и общие противоречия всё ещё ограничены. Нужны отдельные контрольные данные.
9. **Приватность.** Фильтры распознают известные признаки секретов; универсального
   распознавания всех личных сведений нет. Локальные описания фото сохраняются в
   истории задач. Сам base64-файл не сохраняется там; после перезапуска до анализа
   потребуется приложить его заново.
10. **Фото и поиск.** После получения описания фото дополнительные поисковые вызовы
    этой задачи отключены, чтобы описание не попало в запрос. Явно запрошенный
    публичный поиск референса выполняется до разбора фото.
11. **Нормализация и понимание.** Разделение намерений в новой задаче детерминированное
    и поддерживает ограниченные формулировки; сложные отсылки могут потребовать уточнения.
12. **Контекст агента.** Бюджет 24 хода/15 минут и упрощённое удаление старых наблюдений
    остаются; длинная работа может терять детали. Отмена не мгновенна при сетевом ожидании.
13. **Совместимость Desktop.** Часть оболочки остаётся в бинарном слое совместимости;
    полный исходный аудит этого слоя не выполнен.
14. **Качество тестов.** Успех тестов инструментов не равен правильности произвольной
    программы. Нужен постоянный раздельный набор реальных задач, ошибок и отрицательных случаев.

Не следует лечить это одним узким словарём тем, незаметно подменять модель,
обучать веса на непроверенных веб-страницах или выдавать статическую проверку за
успешный запуск приложения.

## Подтверждённые проверки

- 95 тестовых функций проходят, включая 20 разных референсов, восстановление после
  JSON-ошибки, поиск черновика, запрет записи вслепую, связанные файлы и фото.
- Регрессия понимания: 120/120 до и после.
- 86 Python-файлов Core компилируются; фронтенд успешно собран.
- Реальная qwen2.5vl:3b прочитала созданную тестовую карточку «META 42», синий
  квадрат и красный круг. Один пример, не оценка универсального OCR.
- Реальная qwen3.5:4b создала index.html, styles.css и app.js; проект завершён,
  проверки выполнены. В отдельном браузере добавление/удаление задач работают,
  ошибок JavaScript нет.
- В тестовой Desktop 5.3.1 прикрепление фото передаёт image в маршрут задачи;
  короткий чат отвечает. В обычном чате загружена карточка и получен ответ с «42»
  через настоящий vision-маршрут. Рабочий профиль для тестов не использовался.
- Установщик установлен в отдельную тестовую папку: код выхода 0, проверка хешей
  самим установщиком, Core 5.3.1 online, Ollama connected, короткий чат проходит.
- Живой запрос об официальном сайте сначала дал две сторонние страницы.
  После изменения фильтра повтор дал 0 открытых страниц и сообщение об отсутствии
  подтверждённой информации. Не следует считать это успешным нахождением сайта.
- Поиск известных форм секретов: 160 текстовых файлов, совпадений нет.
  Это проверка шаблонов, а не гарантия отсутствия любого секрета.

При проектировании использовался принцип «контекст → действие → проверка»,
описанный в [официальной документации Claude Code](https://code.claude.com/docs/en/how-claude-code-works).
Реализация META собственная; обещания равного качества нет.
