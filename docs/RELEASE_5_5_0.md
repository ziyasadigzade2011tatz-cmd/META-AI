# META Studio 5.5.0

Обновление от 10 ноября 2026 года. Windows x64.

## Что изменилось с публичной 5.3.1

- Обновлён интерфейс и персонализация; добавлено удаление разговоров с подтверждением.
- Убран обязательный пароль локальной оболочки. Проверки локального адреса и источника запросов сохранены.
- Повторный запуск профиля обращается к одному экземпляру приложения; разные профили могут открываться отдельно.
- Улучшена загрузка материалов: состояние обработки, ошибки пустого текста, повторная загрузка того же файла, разбиение длинного текста.
- META Code поддерживает Qwen 3.5 4B/9B и установленную Mimo V2.6 9B. У Mimo используется оценка токенов с запасом; точность framing не заявляется.
- Контекст и ответы агента ограничены токенными бюджетами; старые результаты инструментов сокращаются. Улучшены обработка done, обрыва потока, таймаутов и повторных проверок изменённых файлов.
- Убрана полная перезапись сессии на каждом обновлении генерации; добавлен ограниченный кэш токенизации.
- Доступны ролевые консультации архитектора/ревьюера на той же модели; проверки синтаксиса и связей файлов могут выполняться параллельно. Параллельной записи файлов несколькими LLM нет.
- Финальная успешная проверка может завершать задачу без отдельного вызова finish.
- Добавлен локальный опыт: короткие поправки пользователя, области задачи/проекта, кандидаты, управление через /learn, забывание и отметки простых противоречий. Это не дообучение весов.
- Неизвестное слово само по себе больше не запускает поиск; целые задания, код и распознанные секреты не отправляются в поисковик.
- В существующем проекте сохраняется контекст предыдущих заданий. Добавлены планы проверок для Python, JS/TS, C#, C++ и интерфейсов с честным статусом незапущенных проверок.
- Исправлен старый жёстко заданный путь установщика: стандартная папка теперь %LOCALAPPDATA%\Programs\META, пользователь может выбрать другую.

## Установка

1. Скачайте META-Setup.exe из этого релиза и запустите.
2. Для обновления выберите папку существующего приложения, предварительно завершив задачи и выйдя из META через трей.
3. Установите Ollama отдельно, если её нет, и загрузите подходящую модель.
4. Запустите META. В персонализации выберите модели по ролям.

Пакет содержит приложение, Python/Core, интерфейс и зависимости приложения.
Веса моделей, Ollama, личные чаты, профили, память и API-ключи в установщик не входят.
Установщик не подписан коммерческим сертификатом. Локальный режим без пароля рассчитан на доверенную учётную запись Windows.
Исходники находятся в studio. Папки local и .venv исключены из Git.

## Проверки и ограничения

- 183 автоматических теста: все успешны, включая согласованность версий Core, оболочки, frontend и setup.
- TypeScript проверен, frontend собран; сборка приложения сообщает версию 5.5.0.
- В браузере проверены открытие без пароля, удаление тестового чата и загрузка TXT, без ошибок JavaScript.
- Установщик проверяется установкой в отдельную тестовую папку с SHA-256 файлов и запуском установленного Core.
- Видеокарта 4 ГБ не вмещает всю 9B-модель. Кратное ускорение Mimo и качество уровня крупных облачных моделей не обещаются.
- Для произвольных проектов сборка, тесты и семантическая приёмка не выполняются автоматически без необходимых инструментов и разрешений.
- OCR сканов и генерация изображений этим релизом не добавлены.
