## Архитектура: сначала решение, затем установка

Python сам по себе не делает ИИ слабым. Качество зависит также от модели,
контекста и инструментов. Полный внутренний стек ChatGPT нам неизвестен;
не выдавать выбор языка за копирование его архитектуры.

1. Проверить актуальные исходники, Git, установщик и реальные узкие места.
2. Сравнить варианты: сохранить Python для моделей; перевести прикладные сервисы
   на TypeScript; вынести отдельные нативные компоненты в Rust. Это варианты
   для оценки, а не принятое решение о полном переписывании.
3. Зафиксировать контракт существующего Core и тесты совместимости. Сохранить
   чаты, настройки, профили, пути запуска и скоростной патч.
4. Подготовить отдельный минимальный прототип одного компонента. Проверить
   запуск, память, скорость и сборку перед переносом остальных модулей.
5. После выбора архитектуры составить точный список устанавливаемых инструментов
   и размеров загрузок. Не подменять рабочую установку непроверенным прототипом.

## Генерация изображений

1. Проверить доступную VRAM/ОЗУ, свободное место и совместимость окружения.
   Ориентир из разговора: 4 ГБ VRAM, 16 ГБ ОЗУ; актуальное состояние проверить.
2. Сверить современные модели по официальным карточкам: качество, лицензия,
   требования, размер, поддержка русского запроса, генерация и редактирование.
   Конкретная модель пока не выбрана. Бесплатные веса не означают бесплатное
   облако или отсутствие затрат времени и ресурсов.
3. Спроектировать отдельный провайдер изображений: запрос → очередь → прогресс →
   результат/ошибка/отмена. Текстовый Ollama и генератор изображений — разные
   компоненты; существующая vision-модель читает фото, это не генератор.
4. На этом ноутбуке не запускать одновременно тяжёлую текстовую и графическую
   модели. Облачный вариант рассматривать отдельно, без обещания безлимитности.
5. Сначала проверить одну генерацию в отдельном прототипе, затем добавить
   вложение результата в чат, сохранение, понятные ошибки и отмену.
