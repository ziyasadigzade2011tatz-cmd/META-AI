# Как пользоваться META Studio

## META Code

Оставь «Новый проект автоматически» и опиши желаемый результат: назначение,
страницы/функции, ограничения. META создаст отдельную папку с ASCII-именем и
уникальным суффиксом. Английское название можно указать в кавычках в запросе.
Папка выбирается по типу задачи, содержимое файлов генерируется по твоему запросу.

Цикл: план → изучение → код → проверка → итог. В новой папке файлы записываются
автоматически; для существующего проекта сначала показываются изменения.
Если исходник изменился извне, применение блокируется. Отдельный запрос на анализ
не должен подменяться созданием кода. Запрос создать код из чата направляется в Code.

Файл открывается нажатием в дереве. Границы панелей перетаскиваются.
«Фокус на коде» скрывает панели; повторное нажатие возвращает их.
Ctrl+B — левая панель, Ctrl+S — сохранение, Ctrl+Enter — запуск задачи в Code.
Кнопка «Папка проекта» открывает настоящую папку в Проводнике.

Предпросмотр предназначен для простых статических сайтов. Он не заменяет сервер
фреймворка; браузерные API в изолированном просмотре могут быть ограничены.
Проверяй окончательную работу обычным запуском в браузере.

Автоматический check проверяет пути, размеры и Python/JSON-синтаксис. Он не
запускает приложение и не объявляет HTML/CSS/JavaScript полностью протестированными.
Отдельно доступны Node.js `--check` и Python unittest. Нужно явно разрешить тесты:
это права пользователя, не песочница. Есть ограничение времени/вывода и Windows Job.
Пакеты проекта, которых нет во встроенном Python, могут быть недоступны.
Менеджер окружений и произвольный терминал не реализованы.

После остановки/ошибки можно продолжить сохранённый черновик. Локальная модель
может ошибаться; на ноутбуке с 4 ГБ VRAM большой ответ может занимать несколько минут.
Замена нескольких файлов атомарна только по отдельному файлу, не общей транзакцией.
При ошибке записи нужно проверить фактическое состояние; автоматический откат не обещается.

## Материалы

Это библиотека документов, заметок и публичных страниц. META ищет подходящие
отрывки и добавляет их в контекст выбранного проекта. Веса модели от этого не обучаются.
Без выбора проекта используется общая область. Форматы требуют поддержки
извлечения текста; отдельно проверялся TXT. Изображение в чате — другое вложение.

## Параметры модели

**Temperature** регулирует разнообразие выбора следующего токена: ниже —
предсказуемее, выше — разнообразнее и иногда менее точно. Это не уровень интеллекта.
Ползунок относится к чату; агент использует собственное низкое значение.

**Контекст** — рабочее окно модели в токенах: инструкции, сообщения, файлы и ответ.
Большое окно требует больше памяти и может замедлять компьютер. Полная история
на диске и текущий контекст — разные вещи; старые части могут сокращаться.

**Память пользователя** — отдельно сохранённые факты и предпочтения для следующих
запросов. Это не переобучение весов. Ошибочный факт не становится истинным от сохранения.
Пароли и API-ключи в память не записывай.

## Оформление и профили

Выбери один из шести пресетов или независимо поменяй основной цвет и акцент.
Цвет текста подстраивается к фону. Плавные переходы отключаются настройкой;
системное уменьшение движения также учитывается.

Профиль снизу слева → имя нового → «Создать профиль» → «Открыть».
У нового профиля отдельное окно, каталог данных и локальная учётная запись.
Старые чаты и память в него не копируются.

## Другой компьютер

Скачай один META-Setup.exe из последнего релиза. Python/Core внутри; Ollama и
модели устанавливаются отдельно. В Персонализации есть кнопки для этого.
Чаты и ключи автора не поставляются. Инсталлятор не создаёт бэкапы и отказывается
писать в известные папки данных, моделей, Core и пути со ссылками/junction.
