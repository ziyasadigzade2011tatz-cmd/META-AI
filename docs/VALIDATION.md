## Границы проверки

Финальная проверка обнаружила ошибку привязки унаследованного обработчика чата:
он искал connect в модуле Studio. В 5.2.1 сохранена исходная привязка модуля;
повторная браузерная проверка обычного чата прошла. Добавлен verify_chat.cjs.

На другом физическом компьютере и чистой виртуальной машине установка не
проверялась. Python, Qt и Core включены; Ollama и веса моделей загружаются отдельно.
Node.js для дополнительной проверки JavaScript необязателен и в пакет не входит.

Это не измерение соответствия Claude Code в процентах. Качество результата зависит
от локальной модели и задачи. Один успешный сайт не доказывает надёжность на всех
проектах. Произвольный терминал, управление окружениями и общая транзакция записи
нескольких файлов не реализованы. Подробные ограничения — в GUIDE_RU.md.

Исходники совместимого базового Desktop доступны не полностью: часть оболочки
поставляется как существующий скомпилированный слой. Новый интерфейс и модули
Studio представлены исходным кодом.
