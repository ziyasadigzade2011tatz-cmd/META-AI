# META Studio 5.3.0 — проверки

Дата: 2026-11-05. Подробный отчёт: [PHASE10.md](PHASE10.md),
[числа понимания до и после](../studio/tests/understanding_results.md).

- 51 модульный тест; дополнительно 120 компонентных случаев понимания.
- 32 прямых локальных вызова qwen3.5:4b на 16 сменах темы: метрика упоминания
  посторонней темы — 2/16 до, 0/16 после. Это не оценка всех свободных ответов.
- Браузерная проверка четырёх списков моделей и сохранения настроек пройдена.
- Отдельный нативный Desktop/Core: /health, короткий чат после изменяющих шагов.
- Межпроцессная очередь с блокировкой файла проверена вторым Python-процессом; повторный захват
  из того же потока отклоняется, что защищает параллельные async-запросы.
- Проверяется совпадение установленных исходников и frontend с финальной сборкой.
- Метаданные существовавших данных сверяются до и после установки, до запуска.

SHA-256 META-Setup.exe:
`a624cb44257f52ace0bba3cacd204d7fc8e9eca688a27139582b196a10617502`

Размер установщика: 290527232 байта. На другом физическом компьютере и чистой
виртуальной машине установка не проверялась. Python, Qt и Core входят в пакет;
Ollama и модели устанавливаются отдельно. Полная морфология, все диалекты и
полноценный облачный транспорт не реализованы. Веб-ранжирование по эмбеддингам
и проверка опоры утверждений относятся к фазе 11, которая пока проходит аудит.

Проверки Code из 5.2: создание трёх файлов сайта, интерактивный предпросмотр,
ручное сохранение и возврат в редактор были пройдены ранее. В фазе 10 отдельно
повторялись модульные проверки агента; тот полный сценарий генерации сайта заново
не запускался. Исходники базового скомпилированного слоя Desktop доступны не полностью.
