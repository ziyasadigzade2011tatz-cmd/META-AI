## Запуск

Рабочий ярлык: `C:\Users\Desktop\META.lnk`.
Его цель: `C:\Users\user\Documents\GitHub\META-AI\local\app\META-Next.exe`.
В корне репозитория также есть `Start_META.cmd` и `Start_Core.cmd`.
Второй запускает отдельный Core на порту 8000: не запускайте его при занятом порту.

Прежний `%LOCALAPPDATA%\META` теперь является ссылкой на `local\data`.
Сами исходные действующие данные физически перемещены, а старые абсолютные пути сохранены через ссылку.
Node больше не требует `D:\META\Tools`. Новая среда Python не требует `D:\META\Core\.venv`.
Ollama использует `local\models`: путь проверен через /api/show.
