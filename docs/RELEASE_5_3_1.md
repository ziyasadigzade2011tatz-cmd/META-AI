`C:\Users\user\Documents\GitHub\META-AI\dist\META-Setup-5.3.1.exe`

Размер: 288506880 байт (около 275,1 МиБ).
SHA-256: `29bf7f5b09d5c198b40171910079104e5cf63b0752f3ed409c87393819d7d6d9`.
Публичное имя после публикации предполагается `META-Setup.exe` в релизе v5.3.1.

локальных конфигов с ключами и моделей. Ollama и модели устанавливаются отдельно,
как и раньше. Node.js нужен для JS-проверок; при его отсутствии они помечаются not_run.

- 101 тестовая функция; регрессия понимания 120/120.
- Компиляция 87 Python-файлов Core; сборка frontend.
- Реальные vision и coding-модели на синтетических материалах.

профиля и содержимое пользовательских чатов в Git не добавляются.

## Подтверждённый порядок развёртывания

1. Закрыть рабочую META и заменить приложение этим проверенным установщиком.
2. Проверить запуск рабочей установки и сохранность данных после обновления.
3. Отправить подготовленные коммиты в META-AI и опубликовать релиз v5.3.1
   с одним устанавливаемым файлом META-Setup.exe.

Данные, `.venv`, ключи, модели и пользовательские проекты не удаляются.
Проверочные сборки находятся в build, это не резервные копии личных данных.
Автоматического удаления истории Git или старых релизов в этот план не включено.
