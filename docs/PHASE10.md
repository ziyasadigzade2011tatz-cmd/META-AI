# Фаза 10 — понимание речи и защита от переноса темы

Сборка META Studio 5.3.0. Исходное состояние: `89880c2`; контрольный коммит перед работой: `cf1c608`.
Все проверки использовали синтетические данные. Пользовательская память не очищалась:
в разрешённой выборке аудита не было записей для удаления. `.pre10` не создавался.
Модели и ключи не пересоздавались. Пакеты в защищённую `.venv` не устанавливались.

## Реализованный конвейер

```text
Исходное сообщение (история сохраняет именно его)
 → локальные команды /slang и /debug, явные определения
 → проверка приватности
 → раскладка / транслит / известные опечатки / повторения / разделение слов
 → словарь с контекстным выбором значения
 → при необходимости локальный JSON-разбор (не более двух попыток)
 → текущий чат: восемь сообщений + его сводка, разрешение отсылки
 → строгий отбор памяти
 → самостоятельный поисковый вопрос либо уточнение
 → обычный ответ с универсальной инструкцией
 → опциональная диагностика
```

Универсальная инструкция читается из `studio/core/config/system.md` при каждом
запросе. Пустые устаревшие поля `game` не передаются модели; существующие поля API
не удалялись. Тематические тесты выбора модели заменены набором по 15 направлениям.
При выборе учитывается доля пройденных заданий, затем среднее время, вместо одного
самого быстрого успешного ответа.

`current_topic` не хранится глобально: он вычисляется из текущего разговора.
Новый самостоятельный вопрос меняет тему; три нерелевантных коротких сообщения
сбрасывают прежнюю. В памяти нет источника темы по умолчанию. Сводка хранится по
идентификатору чата и обновляется на интервале шести сообщений. Старые выдержки и
материалы допускаются в основной промпт только при релевантности.

## Словарь и обучение

Стартовый `config/slang.json`: 344 записи, 21 раздел; игровой раздел — 16 записей.
Есть разговорные сокращения, грубые выражения, профессиональная и региональная
лексика. Ни один раздел не превышает 8%. Добавлены явные варианты и формы части
существительных. Полнота всех русских словоформ не заявляется.

Изменения хранятся отдельно: `%LOCALAPPDATA%\META\core_state\slang.sqlite`.
Журнал `slang_changes.log` содержит только слово, действие и источник. Тексты
сообщений не журналируются. Подтверждённые пользовательские определения имеют
приоритет; кандидаты не подменяют исходное слово. Отвергнутые значения сохраняются.
Автоматическое продвижение требует трёх согласованных наблюдений в двух чатах.
Кандидаты без новых наблюдений удаляются через 90 дней вместе со счётчиками.

Команды: `/slang`, `/slang candidates`, `/slang add слово=значение`,
`/slang confirm слово`, `/slang reject слово`, `/slang remove слово`, `/slang export`.

Веб-проверка выключена по умолчанию. Если включить её, во внешний запрос попадает
только отдельное слово. Лимиты по умолчанию: 5 в час и 30 в сутки. Используется
Викисловарь как открытый лексический источник; один источник даёт кандидата, не
автоматическое подтверждение. Второго независимого словарного источника в этой
версии нет. Региональные определения дополнительно сверены по страницам
[«мультифора»](https://ru.wiktionary.org/wiki/мультифора) и
[«вехотка»](https://ru.wiktionary.org/wiki/вехотка).

## Память и приватность

В фазе 10 основной отбор памяти строго лексический: порог 0,65, до 5 записей,
до 2400 символов. Это **не** гибридный поиск фазы 11. Без совпадения значимых слов
предпочтения больше не подмешиваются автоматически. Семантическая подсистема
старой версии остаётся в коде, но основной `Memory.relevant` её не вызывает.

Распознавание личных данных эвристическое: ключи, пароли, пути, почта, длинные
номера и явные адресные признаки не идут в словарь или веб-поиск. Оно не доказывает
идеальное распознавание любых имён и произвольно замаскированных секретов.
Облачного транспорта фазы 9 в текущей ветке нет. Разбор и обучение — локальные.

## Роли моделей

В Персонализации доступны Fast, Thinking, Code, Understand и переключатель Thinking.
Ручной выбор в верхнем списке больше не перекрывается скрытым флагом Thinking.
Роли сохраняются через отдельный Desktop-маршрут; публичные маршруты Core и их
обязательные поля сохранены. Understand хранится в локальном `core_config/models.json`.

Стартовые значения: Understand/Fast — `qwen3.5:4b`, Thinking/Code — `qwen3.5:9b`.
Это предварительное назначение по доступности и проведённым проверкам; полноценного
сравнения 4B и 9B нет. Межпроцессная блокировка файла на Windows и локальная очередь сериализуют вызовы новых
процессов META. При смене роли прежняя резидентная модель выгружается через
Ollama `keep_alive: 0`, без удаления весов. Другие программы могут обращаться к
Ollama независимо от очереди META.

## Проверки и границы

[Числа до и после](../studio/tests/understanding_results.md): 120 компонентных случаев,
отдельно 32 вызова локальной модели на 16 сменах темы. Эти проверки не доказывают
100% качества свободного общения. Полной морфологической модели нет; используются
словарь, консервативные основы и правила. SMS-формы и диалекты охвачены частично.
Отсылки разрешает локальный JSON-разбор с проверкой привязки к текущему чату;
при сбое остаётся консервативный запасной разбор. Сложные случаи могут требовать
уточнения. Веб-ранжирование и проверка опоры утверждений относятся к фазе 11.

В шагах 3, 9, 10 и 11 были неудачные проверки: незакрытое соединение SQLite, раннее
нажатие тестом до загрузки интерфейса, недостаточная полнота сленга и отсылок, столкновение теста с рабочей очередью.
Тесты блокировки теперь используют отдельный временный каталог. Офлайн-предпочтение
передаётся служебным системным маркером и не меняет сохраняемый текст сообщения;
проверены исходная история, запрет поиска, команды и освобождение очереди после ответа.
Изменения соответствующего шага убирались через Git stash, затем вносились с
исправлениями и повторно проверялись. Рабочие данные при этом не участвовали.

После каждого изменяющего шага проверялся отдельный нативный runtime с собственными
данными: Core на свободном порту, `/health`, чат через Desktop HTTP-мост. Рабочий
ярлык проверяется при окончательном применении; это не отдельная проверка ярлыка
после каждого промежуточного коммита.

## Отключение и откат

Флаги — `_internal/core/config/understanding.json`. Локальные переопределения можно
положить в `%LOCALAPPDATA%\META\core_config\understanding.json`:

```json
{"normalizer": false, "slang_learning": false, "web_slang_lookup": false, "debug": false}
```

`debug` задаёт начальное состояние; `/debug off` отключает ранее включённую
диагностику конкретного чата. `/debug on` показывает нормализацию, тему, запросы,
выбранные словарные записи и память с оценкой. Личные подробности скрываются.

Для отмены кода фазы в чистом Git-дереве:

```powershell
git revert --no-commit cf1c608..phase10-complete
git commit -m "revert phase 10"
```

Затем заново собрать и установить отменённый код. Git не откатывает пользовательские
базы: они не коммитятся. Новые словарные файлы при откате можно оставить — прежний
код их не использует. Никаких команд удаления личных данных для отката не требуется.
