# Обновление интерфейса и запуска META

Установлено в `C:\Users\user\Documents\GitHub\META-AI\local\app`.

## Изменено

- Более спокойное оформление: поверхности, отступы, карточки, поля, состояния фокуса и персонализация. Пользовательские цвета и настройка уменьшения движения сохраняются.
- Экран входа убран. Локальная оболочка больше не требует пароль. Файл аккаунта, чаты и память не удалены. Доступ проверяет loopback-адрес и Host; проверки Origin изменяющих запросов сохранены. Это режим доверенного локального пользователя, а не защита от других программ в той же учётной записи Windows.
- Один новый экземпляр Desktop на каталог данных через Windows mutex. Повторный запуск отправляет сигнал существующему процессу для восстановления окна. Разные профили могут открываться отдельно. Проверочные серверы и дочерний Core не блокируются этим механизмом.
- Кнопка удаления каждого чата с подтверждением. Во время ответа текущий чат сначала нужно остановить. Используется существующий серверный маршрут DELETE; пользовательские разговоры при проверке не удалялись.
- Материалы: состояние «Читаю документ», блокировка повторной отправки, понятное сообщение для пустого текста, предупреждение о частичном извлечении, сброс выбора файла после обработки. Длинный извлечённый текст разбивается на части до 100000 символов — лимит существующего хранилища. Повторная загрузка того же файла возможна. OCR для сканов не добавлен.
- Проект получает предлагаемое моделью название из первого plan.title. Оно показывается в карточках. Нужен план с title; старые проекты без названия продолжают показывать имя папки. Переименования папок и отдельного запроса к модели нет.
- Исправлен оставшийся запасной контекст frontend: 8192 вместо 4096. Явно выбранные настройки не переписываются.

## Производительность

Сохраняются ранее установленные токенные бюджеты, think=false для кодинга,
ограничение ожидания и поддержка Qwen/Mimo. Новый механизм единственного экземпляра
предотвращает лишние новые оболочки/Core одного профиля. Название проекта генерируется
в уже существующем вызове плана, без дополнительной смены модели.
Настройки GPU, веса моделей и конфигурация Ollama не менялись.
Нового доказанного ускорения токенов/секунду или полной оптимизации 9B на 4 ГБ VRAM не заявляется.

## Проверки

- 165 автоматических тестов: все успешны, 12.815 с.
- Все 158 Python-файлов studio компилируются в памяти.
- TypeScript проверен, production frontend собран Vite.
- Настоящий Windows mutex: второй процесс с тем же каталогом получает отказ на запуск, другой профиль разрешён.
- Browser-проверка установленной оболочки без cookies: вход без пароля, создание/удаление синтетического чата, добавление TXT, открытие персонализации; ошибок JavaScript нет.
- Визуально просмотрен снимок персонализации. Снимки находятся в local/maintenance/desktop-*.png.
- Проверки выполнены в отдельном тестовом профиле; действующие аккаунт и разговоры не изменялись.
- Визуальное восстановление свёрнутого настоящего окна через Windows foreground API отдельно не подтверждено; система Windows может ограничивать перевод фокуса.
- PDF/DOCX/XLSX поштучно в этом обновлении не проверялись; успешная проверка загрузки относится к TXT.

## Применение

Исходники, frontend и тесты скопированы в рабочее приложение. Старые запущенные
процессы всё ещё содержат ранее импортированный код. После завершения текущей задачи
выберите «Выход» в меню каждого старого значка META в трее и снова откройте ярлык.
Простое закрытие окна может только свернуть его в трей. После этого новые повторные
запуски одного профиля будут обращаться к одному экземпляру.

Публичный установщик и GitHub-релиз этим изменением не пересобирались.
Checkpoint перед изменениями: 2b08cbd. Для отката исходников используйте git revert
коммита обновления, затем синхронизируйте его файлы с установленной копией и frontend.
