# META 5.3.2 — видимый прогресс META Code

## Что исправлено

Desktop META Code получает действия через поток JSON с `think=false`, вместо
ожидания буферизованного native tool call. Выбранная пользователем модель сохраняется.
Во время ожидания, подготовки модели и генерации обновляются этап, время и число
полученных символов. Частичный код показывается как незаписанный черновик.
Незавершённый JSON никогда не исполняется и не применяется к проекту.

Qwen может возвращать параметры непосредственно рядом с `action`, а не в `args`.
Для текущих запросов Ollama задана строгая JSON-схема действия и его аргументов. Оба варианта полученного ответа дополнительно приводятся к одному формату для известных инструментов. Противоречивые
параметры и неизвестные действия отклоняются; проверки путей и подтверждение изменений
существующего проекта сохранены. Плоский `finish.summary` тоже поддерживается.

Тайм-аут больше не создаёт бесконечную серию приглашений «Продолжить задачу».
Временная ошибка получает ограниченное число автоматических повторов. При исчерпании
бюджета задача заканчивается с объяснением и сохранённым черновиком. Повтор после
ошибки или ручной остановки остаётся отдельным действием пользователя.
Неоднозначный запрос всё ещё может потребовать уточнения.

История через `get()` распознаёт оставшиеся после закрытия приложения задачи как
прерванные. Старые файлы сессий при просмотре не переписываются.

Фразы «без веб-поиска», «без поиска» и «не используй веб-поиск» распознаются как запрет,
а не как обязательный поиск, который затем падает из-за отключённой сети.

## Интерфейс

В META Chat и META Code добавлены панели «Действия»: раскрытие/сворачивание,
закрытие и повторное открытие, кнопка «Стоп», план, инструменты, файлы и проверки.
Панель Code видна и при переходе в чат. Свёрнутое состояние сохраняется при опросе
задачи. Обновление панели не пересоздаёт редактор или поле ввода.
Показываются события инструментов и черновик кода, а не скрытые рассуждения модели.

Чат передаёт идентификатор активного сеанса и отменяет его через существующий
маршрут Core. Desktop добавляет только внутренний `/studio/cancel-chat`.
Публичные форматы и маршруты Core сохранены. Отмена охватывает и локальный
LLM-разбор запроса: HTTP-запрос закрывается, очередь вычислений освобождается.

## Ограничения и настройки

`studio/core/config/agent.json`, локальное переопределение — файл `agent.json`
в каталоге `META_CORE_CONFIG_DIR`:

| Настройка | По умолчанию |
|---|---:|
| `step_seconds` | 300 |
| `queue_seconds` | 300 |
| `total_seconds` | 1800 |
| `max_steps` | 72 |
| `transient_retries` | 2 |
| `heartbeat_seconds` | 1 |
| `progress_seconds` | 0.75 |

Все бюджеты ограничены в коде. `total_seconds` ограничивает также текущий вызов
модели; число попыток конечно. Ограничения Desktop не меняют отдельный агент
основного Core. Частота интерфейса — опрос примерно раз в 1,5 секунды.

На ноутбуке с 4 ГБ VRAM 9B остаётся медленной. Поток не увеличивает скорость модели.
Модель Code не заменена автоматически на 4B. Скоростные настройки обычного чата
сохранены. Первичный веб-поиск и чтение изображения имеют собственные ограничения;
мгновенная отмена каждого внутреннего сетевого/vision-этапа не проверена.
