  Правки существующих файлов и запрет слепой перезаписи сохранены.

## Как учится опыт

Это локальная база правил и результатов, **не дообучение весов**.
Она не читает старую переписку целиком и не собирает интернет.

`Поправка: для экспорта используй формат CSV` сохраняет короткое подтверждённое
правило в области выбранного проекта. В следующем задании про экспорт этого
проекта правило попадёт в контекст. В другом проекте и в вопросе об оформлении
меню оно не используется. Этот сценарий проверен автоматическим тестом.

Подтверждаются явные конструкции `Поправка: …`, `Запомни: …`, `Впредь: …`.
Фразы `Нет, …`, `Не так: …`, `Я имел в виду: …` сохраняются кандидатами;
до подтверждения они не добавляются в следующие запросы как правила.
Примеры с «например»/«как пример» не сохраняются автоматически.
Ответ модели не может автоматически стать подтверждённым знанием.

Области: текущая задача, выбранный проект, явно заданное общее предпочтение.
Отбор основан на совпадении области и ключевых слов с короткими основами слов.
Для общих правил требуется больше совпадений. В контексте максимум шесть правил,
текст блока ограничен 1800 символами и общим токенным бюджетом.

Запись содержит правило, обозначение причины, область/ключ области, источник,
уверенность, статус, время, поле evidence и ссылку на заменившую запись.
При редактировании старое правило становится replaced. Простые противоречия
по совпадающим словам и явному отрицанию помечаются; чат задаёт уточнение,
а кодинг-задача приостанавливается. Полное смысловое разрешение противоречий
не реализовано. Поле evidence не заполняется выдуманными подтверждениями.
Результаты проверок сохраняются отдельно по ID задачи и не повышают сами
по себе статус или уверенность правила.

## Управление

Команды доступны в обычном чате и поле задачи META Code:

```
/learn list
/learn candidates
/learn add Для экспорта используй CSV
/learn global Для экспорта таблиц используй CSV
/learn confirm 12
/learn reject 12
/learn edit 12 Для экспорта используй JSON
/learn forget 12
/learn off
/learn on
```

`забудь это правило` забывает единственное последнее подобранное правило
текущей задачи/разговора. При неоднозначности требуется номер; все правила
автоматически не удаляются. Команда off отключает автоматический захват,
подбор правил и запись результатов; ручное управление остаётся доступным.

База: `local/data/core_state/experience.sqlite` в рабочей установке.
Она исключена из Git. Хранятся короткие правила, служебные метаданные,
ссылки на последние подобранные ID и категории/статусы проверок.
Исходный код, полные документы, ответы модели, пароли и ключи туда не копируются
намеренно; фильтр секретов эвристический и не гарантирует распознавание любых личных сведений.
Существующие чаты, память и базы не мигрировались и не очищались.

## Проверка любых проектов

Существующие проверки синтаксиса и связей файлов сохранены. Добавлен inventory
подходящих следующих проверок: Python unittest, JS-тесты, TypeScript types,
.NET build/tests, CMake/toolchain и, для HTML, поведение интерфейса.
Статусы различают not_run, requires_tool и tests_not_found.
Зависимости не устанавливаются; сборка и исполнение не запускаются без разрешения.
Это план проверок, а не новый универсальный исполнитель всех toolchain.

В деталях задачи сохранён assessment: план проверок и критерии с честным
not_verified. Синтаксис автоматически не объявляется выполнением всех требований.
Самостоятельная семантическая приёмка произвольного проекта не реализована.
Защита от повторов с учётом состояния файлов и существующие специалисты сохранены.
Собственный код по-прежнему можно читать и готовить в отдельном рабочем Git-проекте;
автоматическая подмена запущенного Core не разрешена.
