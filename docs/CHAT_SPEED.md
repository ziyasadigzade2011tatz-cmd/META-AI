# Скорость обычного общения — 5 ноября 2026

Изменение проверено и применено к существующей установке
`C:\Users\Desktop\META_FULL_DESKTOP\META-Next`.
Это отдельный небольшой патч поверх установленной фазы 10. Незавершённая фаза 11
из рабочего репозитория в эту установку не переносилась.

## Что изменено

- Обычный автоматический чат: `qwen3.5:4b`, Thinking выключен.
- Глубокий поиск выключен по умолчанию; разрешение обычного поиска сохранено.
- Модель удерживается в памяти до 900 секунд вместо 180. При выборе другой модели
  прежняя по-прежнему выгружается, чтобы не загружать две тяжёлые модели одновременно.
- Для точно распознанных отдельных приветствий и благодарностей пропускается
  дополнительный LLM-разбор нормализатора. Исправление текста и словарь остаются.
  Составные сообщения и вопросы этот обход не используют.
- Веса, квантование, температура, размер контекста, лимит ответа, инструкции,
  инструменты и ручной выбор моделей не сокращались.
- Модель Thinking и модель Code не заменялись; их можно выбирать как раньше.

Патч не ускоряет сами вычисления нейросети. Он убирает ненужный тяжёлый режим
обычного чата и уменьшает повторные загрузки. Удержание модели расходует RAM/VRAM
дольше; по истечении срока Ollama может её выгрузить.
Параметр `keep_alive` подтверждён [документацией Ollama](https://docs.ollama.com/api/chat).

## Настройки и отключение

Общие параметры патча: `studio/core/config/performance.json`.
В установленной программе: `_internal/core/config/performance.json`.
Локальное переопределение: `%LOCALAPPDATA%\META\core_config\performance.json`.

| Поле | Назначение |
|---|---|
| enabled | Включает оптимизации; false возвращает удержание 3 минуты и прежний разбор приветствий |
| keep_alive_seconds | Удержание модели, от 0 до 3600 секунд |
| simple_turn_fast_path | Пропуск LLM-разбора для отдельных приветствий/благодарностей |
| greeting_limit_seconds | Порог выбора по замерам, сейчас 20 секунд |
| preferred_chat_model | Предпочтительная модель в сравнении |
| fallback_chat_model | Модель при превышении порога |

Изменение `enabled` само по себе не возвращает настройки Thinking и глубокого поиска:
они хранятся отдельно в `%LOCALAPPDATA%\META\core_state\advanced.json`.
Thinking можно снова включить в персонализации. Модели Fast/Thinking/Code выбираются там же.
При больших запросах, поиске, изображениях и кодинге задержки будут другими.

Для повторного сравнения из корня репозитория:

```powershell
& 'D:\META\Core\.venv\Scripts\python.exe' -B studio/build_tools/benchmark_chat_speed.py
```

Откат исходников — `git revert` коммита с сообщением
`perf: measured Qwen chat defaults and longer model residency`.
Это не откатывает пользовательские данные и не переустанавливает файлы рабочей программы.
Чтобы отключить оптимизации в рабочей программе без переустановки, создайте локальное
переопределение `performance.json` с `{"enabled": false}` и перезапустите META.
Исходное состояние настроек до применения: Fast `qwen2.5:3b`, Thinking включён,
глубокий поиск включён. Возврат этих режимов снова увеличит обычные задержки.
