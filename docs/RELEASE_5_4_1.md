## Управление и откат

Для диагностического отключения нового бюджета существует параметр enabled=false
в локальном context_budget.json каталога META_CORE_CONFIG_DIR. Такой override
при установке не создавался; отключение возвращает прежний символьный механизм,
который не гарантирует соблюдение контекста.

Git сохраняет исходники до и после переноса. Откат Git сам по себе не откатывает
установку: для смены версии требуется собрать и применить соответствующий пакет.
Чаты, память и настройки откатывать или заменять для этого не требуется.
