# META 5.3.3 — продолжение генерации, панель действий и языки

## Подтверждённая причина остановки

В последней изученной задаче использовалась Qwen 3.5 9B. После плана агент не
закончил запись `index.html`: сработал предел 300 секунд, затем два автоматических
повтора. Последний поток содержал 4262 символа и закончился около 299,8 секунды.
Готовых файлов в наборе изменений не было. Незавершённый JSON раньше отбрасывался,
поэтому повтор начинал генерацию заново. Это не доказательство долгого «обдумывания».

Панель целиком заменяла DOM и принудительно прокручивалась вниз. Таймер Code
зависел от успешного опроса сервера, поэтому при задержке выглядел замершим.

## Что изменено

- Панель обновляет отдельные узлы, сохраняет ручную прокрутку и фокус. Таймер
  работает отдельно, раз в секунду. Счётчик отражает полученные символы текущей
  порции; он не выдумывает прогресс при отсутствии данных.
- Опрос идёт последовательно, без перекрытия запросов. Через 8 секунд ожидания
  показывается проблема связи, затем выполняется повтор опроса без перезапуска задачи.
- Поток, оборвавшийся по длине, времени или сетевой ошибке, по возможности сохраняется
  как незаконченный черновик. Незавершённый JSON не исполняется как команда.
- Новый `append` продолжает подготовленный файл по SHA-256 его текущего состояния.
  Старый хеш отклоняется; совпадающий длинный суффикс/префикс не дублируется.
  Повторное объявление уже созданной Python-функции требует `edit`, а не копирования.
- Для Python по возможности выбирается синтаксически целый префикс. Незаконченные
  файлы помечены отдельно: `finish` и применение блокируются до их завершения.
- Размер следующего ответа увеличивается при обрыве по длине. Файл и проект
  могут создаваться несколькими вызовами. Требование «до 60 строк» удалено.
- История сжимается с сохранением исходной задачи и свежего результата инструмента;
  модель получает список текущих черновиков. Это приблизительный бюджет текста,
  а не точный подсчёт токенизатором модели.
- Ошибка до начала рабочего цикла освобождает активную задачу. Итог не повторяет
  неподтверждённые заявления модели о тестах/сборке.

## Продолжение старой задачи

В «Проекты и задачи» открой нужную сессию. При остановленной задаче доступна кнопка
«Продолжить с черновика». Для старой 5.3.2 можно восстановить сохранённый предпросмотр
нового файла, если счётчик не превышал 12000 символов и файл ещё не существует.
Урезанный хвост большого файла не выдаётся за полный исходник.

Модель можно выбрать в верхнем списке до продолжения. Без явного выбора более
лёгкой модели профиль Code самовольно не заменяется. Старые сессии при установке
не мигрируются и не запускаются автоматически.

## Языки и справка

Добавлены пять профилей и пять локальных памяток в `studio/core/config/coding/`:
Python, JavaScript, CSS, C#, C++. Профиль выбирается по текущей задаче и файлам;
консольная задача C# не получает веб-профиль только из-за фразы «не сайт».
Инструмент `language_help` выбирает нужный раздел локальной справки. Это инженерные
инструкции и справочные материалы, не обучение весов модели и не установка SDK.

Источники для уточнения правил:

- [Python Tutorial](https://docs.python.org/3/tutorial/).
- [JavaScript Guide, MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide).
- [CSS, MDN](https://developer.mozilla.org/en-US/docs/Web/CSS).
- [C#, Microsoft Learn](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/).
- [C++, Microsoft Learn](https://learn.microsoft.com/en-us/cpp/cpp/).

Поддержаны дополнительные исходники и файлы проектов: `.mjs`, `.cjs`, `.pyi`,
`.hpp`, `.cc`, `.cxx`, `.hxx`, `.csproj`, `.sln`, `.slnx`, `.props`, `.targets`,
`.resx`, `.svg`. Проверки: AST Python, синтаксис JS через Node без исполнения,
структура скобок/строк CSS, XML файлов проектов C#. CSS-проверка не является полным
парсером или оценкой дизайна; C# и C++ не объявляются скомпилированными.
Существующий opt-in запуск тестов сохранён; произвольное исполнение не включалось.

## Бюджеты Code

В `studio/core/config/agent.json`: 4096 выходных токенов сначала, до 8192 после
увеличения; до 900 секунд на действие, 3600 секунд на задачу, 72 действия,
до двух повторов неисправимого запроса. Существующие локальные переопределения
настроек имеют приоритет. Это конечные предохранители, не платный баланс токенов.
Лимит и скоростные настройки обычного чата в этой работе не менялись.

## Проверки

- 128 модульных тестов успешно: фрагменты, продолжение, неверный хеш, перезапуск,
  защита путей, незавершённые файлы, повторы, справка, сжатие истории и ошибки запуска.
- 120/120 офлайн-сценариев понимания речи; это не оценка свободных ответов модели.
- Реальная Qwen 4B, тест начинался с 256 выходных токенов: 190,2 секунды,
  два восстановления фрагмента, два `append`, увеличение до 1024 токенов, два файла,
  четыре ожидаемые функции без дубликатов. Незавершённых файлов и предупреждений нет.
  Проверены наличие функций и синтаксис; выполнение сгенерированной программы этим
  тестом не подтверждается. В раннем прогоне найдены повторы текста и исправлены
  до подготовки пакета.
- Edge/Playwright: стабильные DOM-узлы и прокрутка, сворачивание/открытие,
  независимый таймер при задержанном запросе, максимум один параллельный опрос,
  обе кнопки остановки; ошибок JavaScript нет. События в UI-тесте подменены.
- Настоящий Desktop → Core передаёт идентификатор активного ответа; Core подтверждает отмену.
- 91 Python-файл Core компилируется без создания `__pycache__`.

Установка рабочего пакета завершилась с кодом 0; сверены SHA-256 всех 4420 файлов.
Контрольные суммы 217 файлов пользовательских данных до первого запуска совпали.

Установленный Core: `/health` отвечает, Ollama подключена, два коротких приветствия
завершились без ошибок за 11,604 с и 1,135 с. Модель чата `qwen3.5:4b`,
Thinking и глубокий поиск выключены, контекст 8192. Это не замер всех типов запросов.

Рабочая оболочка открыта через `C:\Users\Desktop\META-Next.lnk`; показан вход
в локальный профиль. Проверка сообщения именно в этом окне ожидает входа пользователя.

## Ограничения

9B на 4 ГБ VRAM остаётся медленной: управление задачами не заменяет более быструю
модель или железо. Полный новый прогон большого сайта на 9B в этой проверке не выполнен.
Модель может ошибаться в алгоритмах и дизайне, а длинное ожидание не гарантирует
качество. Автоматического обязательного браузерного тестирования каждого проекта нет.
Справки не дают знания всех библиотек и всех версий API.
