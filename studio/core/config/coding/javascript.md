# JavaScript: рабочая памятка META Code

## Среда и структура
Определи браузер это или Node.js. Прочитай package.json, его type и scripts.
Не смешивай import/export и CommonJS без причины. Для обычной страницы свяжи HTML,
CSS и JS реальными относительными путями. Для приложения выделяй состояние,
представление и доступ к данным; не превращай один обработчик в несвязанный набор
условий. Не подключай фреймворк, если пользователь просит чистый JavaScript.

## DOM, события и обновление интерфейса
Пользовательские строки назначай через textContent. addEventListener предпочтителен
для событий; делегирование удобно для динамического списка. Убирай слушатели и
таймеры при уничтожении компонента. Обновляй изменившийся узел, а не весь экран.
Сохраняй фокус, выделение и позицию прокрутки. Автопрокрутка допустима, когда человек
уже находится внизу; при ручном чтении выше она должна прекращаться. Состояние
раскрытия панели принадлежит интерфейсу и не должно сбрасываться от ответа сервера.

## Async, fetch, отмена и повторы
Обрабатывай исключения async-функций. fetch не считает HTTP 404/500 исключением:
проверяй response.ok. Для ожидания используй AbortController и ограниченный тайм-аут.
Не запускай новый опрос, пока предыдущий запрос не закончился. Игнорируй устаревший
ответ после смены задачи. Интервал секундомера не должен зависеть от прихода сети.
Отдельно показывай отсутствие связи, загрузку, ошибку и успешное завершение.

## Данные, доступность и проверка
JSON.parse окружай обработкой ошибки, проверяй тип и обязательные поля результата.
Для действий используй button с понятным названием и доступом с клавиатуры. Пиши
тесты для нажатия, отмены, повторного запроса и пустого ответа. Проверка Node --check
не запускает приложение и не проверяет DOM. Браузерную работу проверяй отдельно:
отсутствие ошибок консоли, подключение ресурсов, ввод, навигация и мобильная ширина.

Источник для уточнения языка: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide
