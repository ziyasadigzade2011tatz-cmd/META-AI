# CSS: рабочая памятка META Code

## Типографика и дизайн-токены
Начни с переменных для фона, текста, акцента, границ, радиусов и отступов. Выбери
небольшое число размеров заголовков и ограничь ширину длинного текста. Иерархия,
выравнивание и свободное пространство важнее количества эффектов. Не подменяй
референс его логотипом и названием; соблюдай заданное имя продукта и палитру.

## Адаптивная сетка и переполнение
Используй Grid/Flexbox по смыслу. Внутри flex/grid задавай min-width:0 там, где
длинный текст иначе раздвигает колонку. Для изображений используй max-width:100%.
Не задавай всему сайту фиксированную ширину. Проверяй узкий экран и горизонтальное
переполнение. Диалогам и кодовым блокам нужны собственные ограничения высоты и
скролл, чтобы они не вытесняли поле ввода и кнопки.

## Hover, стекло и плавность
Hover может менять transform, тень и цвет, но не должен сдвигать соседние элементы.
Для подсветки со стороны курсора передавай координаты в CSS-переменные и ограничь
обновление одним requestAnimationFrame. Стеклянная поверхность требует читаемого
текста и фона; добавляй запасной вариант без backdrop-filter. Не накладывай много
больших размытий и теней на весь экран. Уважай prefers-reduced-motion и сенсорные
экраны без hover. Сложная анимация не должна мешать основному действию.

## Доступность и проверка
Сохраняй заметный focus-visible. Цвет не должен быть единственным признаком ошибки.
Не скрывай необходимую кнопку только потому, что на неё не наведён курсор.
Проверь закрытие скобок, кавычек и комментариев, но не называй это полной проверкой
CSS. Неизвестные свойства, визуальное качество, контраст, высота строк и поведение
на разных размерах требуют проверки в браузере.
