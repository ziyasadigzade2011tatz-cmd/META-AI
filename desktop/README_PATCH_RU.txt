META 1.3 — исправления без изменения версии
========================================

1. Закрой META 1.3, затем дождись завершения окна приложения.
2. Распакуй этот архив в новую временную папку (не поверх старой META).
3. Запусти Apply_hotfix.cmd.
4. Введи ПОЛНЫЙ путь до установленной папки META_Desktop_1_3,
   например C:\Users\user\Downloads\META_Desktop_1_3.
5. Запусти существующий META.exe в СТАРОЙ папке.

Патч сохраняет базу аккаунта, чаты и настройки. В каталоге установки
создаётся backup_before_hotfix_YYYYMMDD_HHMMSS для отката.

Что исправлено:
- определение ui_running на реальном порту UI 8767;
- Software WebEngine rendering по умолчанию для борьбы с мерцанием;
- размытие фона модальных окон убрано, анимации стали легче;
- аватар профиля выровнен в узком меню; удалена стрелка вниз;
- исправлена подпись версии на странице «О программе».

Если ПОСЛЕ патча будут артефакты рендеринга, можно протестировать режим
GPU, запуская через PowerShell так:
$env:META_GPU='1'; & 'D:\META\Core\.venv\Scripts\python.exe' 'ПУТЬ\meta_desktop.py'

META CODE — экспериментальный этап 1, отдельно от графического META Code
------------------------------------------------------------------------
В папке metacode находится действительно исполняемый агент (а не новые
ярлыки для имен агентов). Он умеет Read, Write, Edit, Glob, Grep и
ограниченный Bash для тестов. Все изменения требуют подтверждения.

Для начала: Start_META_Code.cmd; рабочая папка D:\META\Projects.
Должна работать Ollama и быть загружена модель qwen2.5-coder:7b.
Можно указать другую установленную модель в metacode\config.json.

Это только ЭТАП 1 твоего большого промпта. Пока нет полноценного TUI
с потоковым выводом, субагентов, git undo, /compact, MCP, облачных
провайдеров, автопроверки и встроенной вкладки агента в Qt. Наличие
интерфейсной вкладки META Code не означает их наличие.

Проверка guardrails:
cd /d ПАПКА_ПАТЧА
D:\META\Core\.venv\Scripts\python.exe -m unittest metacode.test_engine -v

Безопасность: Bash — это исполняемый код, даже разрешённый pytest может
запустить произвольный Python внутри недоверенного проекта. Не открывай
чужие проекты без проверки и не запускай команды, которых не понимаешь.

Для полностью автономного Windows EXE сборку нужно выполнять на Windows
через Build_Standalone_EXE.cmd; META.exe в папке пока лаунчер, а не
самодостаточная сборка Ollama+Python+моделей.
