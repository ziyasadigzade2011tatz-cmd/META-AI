META Desktop 1.3 — тестовая сборка Windows

НОВОЕ
— Отдельное нативное окно Qt WebEngine вместо Chrome/Edge
— Оранжево-графитовая палитра по умолчанию; темы полностью меняют фон/панели
— Монохромная чёрно-белая тема, синий, графит, оранжевый и другие варианты
— Фирменный чёрно-белый логотип; его нажатие сворачивает/разворачивает боковую панель
— Профиль внизу открывает раздел «Общее»; отдельной кнопки настроек нет
— Отдельная секция META Code с выделенной историей и направлением coding-модели
— Сохранены заметки, чаты, локальный пароль, работа с фото и META Core

УСТАНОВКА (ПЕРВЫЙ ЗАПУСК)
1. Распакуй архив в D:\META\Desktop\META_Desktop_1_3 (полностью, а не только exe).
2. Останови старое окно приложения; Ollama должна быть установлена.
3. Один раз запусти Install_META_1_3.cmd. Он установит PySide6 6.12 и PySide6-WebEngine в виртуальное окружение Core. Потребуется интернет и примерно сотни МБ.
4. Открой META.exe — Windows-запускатель откроет ОТДЕЛЬНОЕ QT ОКНО, а не Chrome.
5. Если возникла ошибка, запусти Start_META.cmd и пришли текст ошибки.

О EXE
META.exe — настоящий PE64 Windows запускатель (а НЕ полностью автономный exe): он использует Python в D:\META\Core и Qt-библиотеки, установленные на шаге 3. Для упаковки графического клиента со всеми зависимостями есть Build_Standalone_EXE.cmd; собирать его нужно на Windows. Упакованный интерфейс всё равно использует твой установленный META Core и Ollama. Эта сборка не была проверена на твоём Windows.

О ДАННЫХ
Память META Core остаётся в D:\META\Memory. Приложение 1.3 использует отдельную локальную историю в data, не удаляет 1.2. Перенос истории из 1.2 автоматически не производится; сначала можно экспортировать чаты 1.2.

META Code пока выделенный режим общения с coding-моделью, не полноценная IDE или автономная система тестирования программ.
Сетевые аккаунты и доступ с телефона ещё не реализованы. Не открывай 8000 или 8767 в интернет.
