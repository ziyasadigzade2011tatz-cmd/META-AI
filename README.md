# META AI — 5.0

Актуальные исходники локального META Core и Windows Desktop.

- `installed_meta/Core/` — действующий Core 5.0, агент, инструменты, память и поиск.
- `desktop/` — действующий Desktop и ресурсы интерфейса.
- `upgrade5/` — проверенный пакет обновления существующей установки, тесты и откат.
- `tools/` — вспомогательные средства проекта.

Подробности: [описание META 5.0](upgrade5/README_RU.md).

На исходном компьютере META 5.0 уже установлена. Для обычного запуска используется прежний ярлык META. Для повторного обновления существующей версии — `upgrade5/INSTALL_META5.cmd`. Старые хеши проверяются: пакет не предназначен для произвольной чистой установки.

## Что требуется отдельно

Windows, Python и окружение Core с пакетами из `installed_meta/Core/requirements.txt`; pytest для соответствующего профиля; Ollama с установленными моделями; PySide6 для Desktop; Git. Для JavaScript/TypeScript и браузера нужны Node, npm, TypeScript, Playwright и Edge. На исходном компьютере инструменты находятся в `D:\META\Tools`; пути задаются в `meta5_tools.json`. Модели и зависимости не включены в Git.

Локальный `meta40_config.json` должен содержать случайный токен и путь проектов. Для новой конфигурации после размещения Core запустите `prepare_local_config.py` внутри Core. Существующую конфигурацию скрипт сохраняет. Это вспомогательная подготовка, а не полный установщик чистой системы.

В репозиторий не включены чаты, аккаунты, память, проекты пользователя, токены, рабочие копии агента, виртуальные окружения и веса моделей. Каталог `installed_meta/Models` содержит только текстовые определения моделей.

46 проверок прошли; поставляемый архив также проверен после распаковки. Полный отчёт находится в документации обновления. Исполнение тестов в Windows выполняется с правами пользователя и требует отдельного разрешения в интерфейсе. Docker на исходном компьютере отсутствует.

Старые архивы, резервные исходники и прежние пакеты обновлений убраны из текущего дерева. История Git сохраняется. Резервные копии на исходном компьютере не удаляются.
