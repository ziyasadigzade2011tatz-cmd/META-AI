## Скачать
Скачать META можно как с github-a так и с сайта **[META](https://site.ziya-sadigzade-2011-tatz.workers.dev)**.

**[Скачать META-Setup.exe](https://github.com/ziyasadigzade2011tatz-cmd/META-AI/releases/latest/download/META-Setup.exe)**

Для установки нужен один EXE из последнего релиза. Старые ZIP-комплекты и патчи
убраны из текущей структуры репозитория. Python и Core входят в сборку.

1. Запусти установщик и выбери отдельную папку приложения.
2. Если Ollama ещё нет, установи её с [официального сайта](https://ollama.com/download/windows).
3. В META открой **Персонализация → Локальные модели** и загрузи модель.
   Для начала — `qwen3.5:4b`; 9B требует больше памяти и может работать медленнее.
4. Создай локальный профиль или войди в существующий. Для разработки открой META Code.

Веса моделей, Ollama и личные данные не входят в установщик. Для первоначальной
загрузки нужен интернет; генерация выполняется локально. Система: Windows 10/11 x64.
Установщик не подписан коммерческим сертификатом.

## Возможности обновления

- META Code создаёт отдельную папку проекта и реальные файлы по запросу.
  «Анализ завершён» без файлов не считается успешным созданием.
- План, чтение/поиск, запись и точные правки; Desktop — до 72 шагов и 60 минут,
  отдельный агент Core — до 24 шагов,
  нативные инструменты Ollama при поддержке моделью, JSON как запасной вариант.
- Поток генерации, остановка, сохранённый черновик и продолжение задачи.
- Большой Monaco-редактор, вкладки, изменяемая ширина панелей, режим фокуса,
  просмотр изменений и защита от перезаписи изменённого извне файла.
- Новый проект записывается автоматически; изменения существующего применяются
  отдельной кнопкой. Копии прежних установок не создаются.
- Python unittest и проверка JavaScript по явному разрешению, ограничение времени
  и вывода. Это исполнение с правами пользователя, не защитная песочница.
- Предпросмотр простого статического сайта и открытие папки проекта.
- Шесть оформлений, независимые основной цвет и акцент, сворачиваемая панель,
  плавные переходы с поддержкой уменьшения движения.
- Отдельные профили; объяснения материалов, Temperature, контекста и памяти.

Ориентиры рабочего процесса: [Claude Code](https://code.claude.com/docs/en/overview),
[Cline](https://github.com/cline/cline), [Continue](https://github.com/continuedev/continue).
Это собственная реализация META, не полная копия этих продуктов и не обещание
одинакового качества модели.

## Данные и обновление

Основные данные Desktop Full — `%LOCALAPPDATA%\META`; дополнительные профили —
`%LOCALAPPDATA%\META Profiles`. Точный путь проекта открывает кнопка **Папка проекта**.
Старые каталоги Preview не объединяются и не переносятся автоматически.

Перед обновлением закрой META через Exit META. Инсталлятор проверяет SHA-256 пакета
и установленных файлов. Данные, ключи и модели не публикуются и не заменяются.

## Разработка

`studio/core` — Core и Studio; `studio/frontend` — интерфейс; `studio/tests` — тесты;
`studio/build_tools` — сборка. Базовый `desktop_base.bin` — исполняемый слой
совместимости существующего Desktop Full. Репозиторий содержит новые Python-модули
и интерфейс, но не все исходники этого скомпилированного слоя совместимости.

Для повторной сборки нужны Windows x64, Python 3.15, PyInstaller 6.22.3,
Node.js/npm, csc .NET Framework и базовый пакет зависимостей Full:

```powershell
Set-Location studio\frontend
npm ci
npm run build
Set-Location ..\..
python -m unittest discover -s studio\tests -v
python studio\build_tools\build_runtime.py --base 'ПУТЬ_К_FULL' --out 'ПОЛНЫЙ_ПУТЬ_К_РЕПОЗИТОРИЮ\build\META-Next'
python studio\build_tools\package_installer.py
```

Результат: `dist\META-Setup.exe`. Сборки, секреты, базы и веса моделей исключены из Git;
официальный установщик публикуется вложением GitHub Release.
