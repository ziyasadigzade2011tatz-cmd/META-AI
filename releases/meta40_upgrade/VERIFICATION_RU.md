# Проверка сборки META 4.0

Проверено 2 ноября 2026 на Windows с Python 3.15.1 из существующей среды META Core.

**17 автоматических проверок: успешно (включая исправление 4.0.1).**

- Границы путей, защищённые имена и файлы, отбрасывание Windows junction.
- Ограничение снимка проекта и исключение скрытых/крупных файлов.
- Полный цикл на управляемом ответе модели: чтение → провал реального unittest → исправление → успешный unittest → многофайловая заявка → применение → откат.
- Лимиты шагов, отмена и обязательное чтение существующего файла перед правкой.
- Отказ при изменении исходника во время задачи и после создания заявки.
- Восстановление нескольких файлов при искусственной ошибке записи.
- Отказ отката при более поздних пользовательских изменениях.
- Явное разрешение тестов и запрет неизвестного профиля исполнения.
- Нулевое число тестов, тайм-аут, ограничение вывода, отмена теста.
- Завершение дочернего процесса: отложенная запись за пределами копии не произошла после тайм-аута.
- Новый API: токен, проверка параметров, жизненный цикл задачи, сохранение истории, статус после перезапуска.
- Блокировка второй параллельной задачи и завершение отменённой задачи.
- Desktop: отклонение постороннего Origin/Host, гостевого доступа и неизвестного маршрута.
- Установка, блокировка повторной установки и точное восстановление исходных байтов.
- Автоматическое восстановление при искусственной ошибке установки.
- Создание новой папки проекта только с разрешением; отказ для выхода за Projects, junction и занятого файлом имени.
- Установка исправления 4.0.1, сохранение прежнего интерфейса, повторный запуск без изменений и точный откат.

**Совместимость с найденными исходниками:** `install_meta40.py --check` успешно обработал реальные Core 3.8 и Desktop 1.3. Подготовлены 12 обновляемых / добавляемых файлов; изменяемый Python-код проходит разбор синтаксиса. JavaScript новой панели проверен `node --check`.

**Настоящая Ollama:** локальная `qwen2.5-coder:14b` прошла пример за 5 шагов: прочитала `calc.py`, прочитала `test_calc.py`, предложила исправление `calc.py`, запустила unittest с результатом `passed`, завершила задачей со статусом `pending`. Исходный файл примера остался без изменений. Полный отчёт — `LIVE_DEMO_RESULT.json`. В этом запуске модель исправила очевидную ошибку до первого тестирования; сценарий с провалом теста и повторным исправлением проверен отдельно автоматическим тестом.

**Установленное исправление:** 4.0.1 применено к найденной установке META. Изменены четыре файла: модуль версии, workspace, API и JavaScript Desktop. Резервная копия находится в `D:\META\Core\meta40_backups\fix401_20261102_053457_781869`. Для загрузки изменений нужно перезапустить Core и Desktop.

**Границы проверки:** установка/откат проверялись на временных копиях контрактов приложения. Полный запуск обновлённого Desktop в Qt и пользовательское подтверждение в его окне не выполнялись. Git/GitHub, pytest/npm и изоляция исполняемого кода средствами Windows не входят в эту версию. Доля сходства с Claude Code не измерялась.
